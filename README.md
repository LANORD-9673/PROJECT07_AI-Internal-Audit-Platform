# NEXUS 2.0
React frontend + FastAPI backend, một địa chỉ web. Dark/Light, logo trong suốt, hiệu ứng chuyển động và loader biểu tượng NEXUS.

Bắt đầu với **HUONG_DAN_REACT_V2.md**.
- Windows: cấu hình .env và chạy START_REACT.bat, mở http://localhost:8000.
- Cloud: deploy Dockerfile; không chạy streamlit_app.py để xem giao diện React.
- Kiểm thử: npm run build --prefix frontend; python -m pytest backend/tests -q.
- Bản Streamlit và tài liệu v1.x giữ để tham khảo. Hướng dẫn của v2 được ưu tiên.

Chỉ dùng dữ liệu mô phỏng; các bước review và giới hạn nghiệp vụ hiện có tiếp tục áp dụng.
